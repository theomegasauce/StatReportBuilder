StatReportBuilder

A desktop app for building statistical reports from CSV data.

Download

Get the latest release for Windows from the releases page.

  1. Download StatReportBuilder-vX.Y.Z-win64.zip
  2. Unzip the folder
  3. Run StatReportBuilder.exe

Note: Windows may show a SmartScreen warning on first run. Click "More info" → "Run anyway".

Developer Setup

pip install -r requirements.txt
python main.py

Build Release

pip install pyinstaller
pyinstaller --noconfirm StatReportBuilder.spec
