📊 StatReportBuilder

Build professional statistical reports from CSV data

About

StatReportBuilder is a powerful desktop application that makes it easy to create beautiful statistical reports from your CSV data. No coding required — just load your data and build comprehensive reports with intuitive visual tools.

⬇️ Download Latest Release 📚 View on GitHub

✨ Key Features

📁 CSV Import

Load and preview CSV files with an intuitive data preview interface.

📊 Visual Report Builder

Create reports using a drag-and-drop interface with no coding required.

📈 Statistical Analysis

Include descriptive statistics, graphs, and advanced calculations in your reports.

📄 PDF Export

Export your completed reports as professional PDF documents.

💾 Project Management

Save and manage multiple report projects with ease.

🖥️ Cross-Platform Ready

Built with Python using Qt — ready to run on Windows, macOS, and Linux.

🚀 Getting Started

Download (Windows)

  1. Go to the Releases page and download the latest StatReportBuilder-vX.Y.Z-win64.zip
  2. Unzip the folder anywhere on your computer (e.g., Desktop or Documents)
  3. Open the unzipped folder and double-click StatReportBuilder.exe
⚠️ First-run note: Windows may show a "Windows protected your PC" SmartScreen warning because the app is not code-signed. Click More info → Run anyway. This is expected for unsigned apps and only happens the first time.
✓ No Python install required! Everything is bundled in the executable.

For Developers

Want to run from source or contribute? Clone the repository and follow the setup guide:

pip install -r requirements.txt
python main.py

Building a Release Locally

pip install pyinstaller
pyinstaller --noconfirm StatReportBuilder.spec

The bundled app will be written to dist/StatReportBuilder/
